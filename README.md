# StudyMate AI

An AI study companion that helps students understand study materials and practice through quizzes.

## Features
- **Study Notes:** Paste notes or textbook content.
- **Simple Explanations:** Find relevant information from your notes.
- **Practice Quizzes:** Answer multiple-choice questions and review correct answers.
- **Quiz Review:** Download your quiz review.

## How to Run
1. Install Python.
2. Install dependencies: `pip install -r requirements.txt`
3. Start the app: `streamlit run app.py`

## Technologies
- Python
- Streamlit

## AI Assistance Disclosure
AI tools assisted with brainstorming, coding, debugging, and documentation. The project uses rule-based text extraction for explanations and quiz generation; it does not currently use a generative AI model.

## Project Status
Hackathon prototype. Features are being tested and improved.
